The directory `reference/sat-track` contains a BASIC program written in BBC basic for the Amstrad NC100/NC200, and its' corresponding description.

Convert the program to Casio JIT Basic and add it to the program 
library, also converting the associated document to markdown format
and the program description in the library.

Use line numbers spaced 10 apart to make it easier to make corrections.

You'll have to take into account the 32x4 character display of the 
Casio VX-4.
