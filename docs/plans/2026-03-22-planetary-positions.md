# Requirements

Write a Casio JIS BASIC program that will run on the FX870P emulator
to calculate the planetary positions given an input date and time, 
relative to an observer on planet earth.

The program should store the observers latitude and longitude
in data statements at the end of the program.

Make the best use of the 32 character by 4 row display.

You have up to 32k of memory to use.
Make of the extended Casio ASCII character set where appropriate.
