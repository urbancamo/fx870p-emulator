# ML Loader

A generic machine-language loader for the FX-870P/VX-4. Receives a compiled `.hex` file over COM0 serial, POKEs the decoded bytes into Bank 1 RAM at `&H1CD0`, verifies a checksum, then executes via `MODE110`.

Companion to the BASIC compiler at `tools/compiler/`. Load this program once — it works for any compiled program.

## Usage

1. Open the library (**LIB**), load `MLLOADER.BAS` into P0
2. Type `RUN` and press `[EXE]`
3. LCD shows `Ready, send .hex now`
4. In the COM0 panel, click **SEND** and pick a `.hex` file generated by the compiler
5. LCD shows progress: `Size=N`, then `Byte I/N` counter
6. On success: `OK. EXE to run...` — press `[EXE]` to run the compiled program
7. On failure: `CHECKSUM ERR got!=want`

## Protocol

The `.hex` file is ASCII text (safe for any serial link — no binary escape hazards). Format:

```
[4 hex chars: 16-bit payload size, big-endian]
[size × 2 hex chars: binary payload, 2 chars per byte]
[2 hex chars: 8-bit additive checksum over payload bytes]
```

Example: a 3-byte binary `48 65 6C` encodes as `000348656C19`:
- `0003` — size (3 bytes)
- `48656C` — payload
- `19` — checksum (0x48 + 0x65 + 0x6C = 0x119 → 0x19 mod 256)

## COM0 Settings

```
OPEN "COM0:6,E,8,1,N,N,N,N,N" FOR INPUT AS #1
```

| Field | Meaning             |
|-------|---------------------|
| 6     | 150 baud            |
| E     | Even parity         |
| 8     | 8 data bits         |
| 1     | 1 stop bit          |

## Target Address

The loader always POKEs to `&H1CD0` (standard FX-870P/VX-4 ML area, same address used by CosmicV4). The compiled programs are ORG'd to match. To use a different address, edit lines 20 (`DEFSEG=`) and 117 (`EX=`).

## MODE110 Quirk

The final line uses a variable for the execution address:

```basic
117 EX=&H1CD0
120 MODE110(EX)
```

Directly passing a hex literal (`MODE110(&H1CD0)`) produces a SN error — Casio BASIC's MODE command parser requires a variable argument. This matches CosmicV4's convention.
