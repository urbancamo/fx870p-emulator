INPUT All Models

Assigns input from the keyboard to a specified variable.

Format

INPUT ["msg" {;|,}] var

Explanation

1. Displays message and waits for input.

2. Separator ; appends "?", , appends nothing.

3. Multiple variables separated by commas.

See

INPUT$ · INKEY$ · INPUT#
