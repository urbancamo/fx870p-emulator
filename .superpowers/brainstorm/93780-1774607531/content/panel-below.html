INPUT

All Models

Purpose

Assigns input from the keyboard to a specified variable.

Format

INPUT ["message" {;|,}] variable [, variable ...]

Example

INPUT "Enter height: "; H

Explanation

1. Displays the message string and waits for keyboard input. The entered data is assigned to the variable.

2. When the separator after the message is ;, a ? is appended to the message. When , is used, nothing is appended.

3. Multiple variables can be specified, separated by commas.

See

INPUT$ · INKEY$ · INPUT# · INPUT@ [Undocumented]
