PRINT

All Models

Purpose

Displays data on the screen.

Format

PRINT [output data] { ; | , } [output data]*

Explanation

1. Output of a numeric or string expression displays the value or string on the screen.

2. Separating output data with semicolons causes each output to be displayed immediately following the previous.

3. Including a semicolon at the end causes the cursor to remain at the position following the output.

How Context-Sensitive Help Works

Keyword Click Interaction

In the BASIC listing, keywords get a dotted underline. Clicking one opens the DOC panel to that command:

30 INPUT "H="; H
→
DOC panel opens → INPUT command page

This works in these locations:

  • BasicListPanel — program listings (P0-P3)
  • LibraryPopup — library program code
  • Error messages — error code links to error docs
