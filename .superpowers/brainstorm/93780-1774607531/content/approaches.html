Manual Integration: Three Approaches

How should the BASIC reference manual integrate with the emulator?

A

DOC Popup + Context-Sensitive Help

A new DocPanel popup (like LibraryPopup) with a sidebar TOC and markdown viewer. Plus keyword-click help: clicking/hovering a BASIC keyword anywhere in the app links to its command page.

Pros

  • Familiar pattern — matches existing popups
  • Keyword help works everywhere (BasicListPanel, Library listings, editor)
  • Single reusable component for all manual viewing
  • Full manual browsable from one place

Cons

  • Popup overlays the emulator — can't see both at once
  • Context switch between coding and docs
B

Integrated Side Panel + Context Help

A dockable DOC panel that uses the existing side-panel layout (like DebugPanel/BasicListPanel). Manual pages render inline beside the calculator. Plus keyword-click help that opens the panel to the right page.

Pros

  • See docs and emulator simultaneously
  • Natural fit with existing layout system
  • Click a keyword → docs panel opens to that command
  • Can browse the full manual in the panel

Cons

  • Panel space is shared with Debug and BASIC panels
  • May need tab management or panel switching
  • More complex layout changes
C

Hybrid: Inline Tooltip + Full DOC Popup

Hover tooltips on BASIC keywords showing a quick summary (Purpose + Format), with a "More..." link that opens the full DOC popup for detailed reading. Best of both worlds.

Pros

  • Quick answers without leaving the flow
  • Full manual available when needed
  • Tooltips are lightweight and unobtrusive
  • Progressive disclosure — summary → full docs

Cons

  • Two components to build (tooltip + popup)
  • Tooltip positioning can be tricky
  • Need to parse Purpose/Format from markdown files

Context-Sensitive Help Locations (included in all approaches)

These are the places where clicking a BASIC keyword would link to its manual page:

  • BasicListPanel — syntax-highlighted program listings (P0-P3 tabs)
  • BasicEditor — the CodeMirror inline editor when editing a line
  • LibraryPopup — library program documentation and listings
  • Error messages — when an error is displayed, link the error code to error docs
  • DOC button — new toolbar button to open the full manual

My recommendation: Option C (Hybrid) — tooltips give instant help without disrupting flow, and the full popup is there when you need to read more. The tooltip component is reusable across all keyword locations.
